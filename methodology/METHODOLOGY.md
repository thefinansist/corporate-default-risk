# Методика версии 1.0

## Цель

Инструмент предназначен для раннего выявления финансового стресса юридического лица по доступной бухгалтерской отчетности. Это предварительный фильтр для очередности углубленного анализа, а не автоматическое кредитное решение.

## Логика расчета

1. Из Excel извлекаются значения по стандартным кодам строк РСБУ за все найденные периоды.
2. По последнему периоду и динамике рассчитываются 11 финансовых индикаторов.
3. Значение каждого индикатора переводится в фактор риска от 0 до 1 по таблице порогов.
4. Баллы индикатора равны `вес × фактор риска`.
5. Итог нормируется только на веса доступных показателей: `100 × сумма баллов / сумма доступных весов`.
6. Полнота показывает долю весов, для которых имеются данные. Низкая полнота не должна трактоваться как низкий риск.

## Стоп-факторы и проверки

Отдельно раскрываются: отрицательный капитал, чистый убыток, текущая ликвидность ниже 0,8, падение выручки более 30%, кредиторская задолженность выше выручки и несхождение строк 1600/1700. Флаги объясняют решение, но в версии 1.0 не добавляют скрытых баллов поверх весовой модели.

## Z″ Альтмана

Справочно рассчитывается `Z″ = 6,56×X1 + 3,26×X2 + 6,72×X3 + 1,05×X4`, где X1 — чистый оборотный капитал/активы, X2 — нераспределенная прибыль/активы, X3 — операционная прибыль/активы, X4 — капитал/обязательства. Применяются ориентиры: выше 2,6 — благополучная зона; 1,1–2,6 — серая; ниже 1,1 — финансовый стресс. Показатель нельзя использовать как самостоятельное решение без проверки применимости к отрасли и качеству данных.

## Переход к настоящей PD

Для статистической вероятности дефолта необходимо собрать срез `компания–дата` и целевое событие дефолта в горизонте 12 месяцев. Рекомендуемый промышленный цикл: определение дефолта → очистка и временное выравнивание данных → train/out-of-time выборки → логистическая/градиентная модель → калибровка вероятностей → ROC-AUC/Gini, KS, Brier score → PSI и мониторинг → экспертное утверждение cut-off и override policy.
